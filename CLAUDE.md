# achillies Team Development Guidelines

## Project Structure
- `src/`: Main application code
- `docs/`: Architecture and design plans
- `prompts/`: System and user prompts used for AI orchestration
- `demo/`: Screenshots and video links

## Code & AI Rules
- Ensure clean code and modular structure.
- Always include explainability (XAI) output for AI recommendations.
- Keep `.env` secrets local and never commit API keys.
